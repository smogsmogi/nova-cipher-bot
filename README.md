# NOVA CIPHER

Бот на GitHub: пишешь текст — в ответ приходит шифр. Алфавит лежит в [`cipher.py`](cipher.py): одна русская буква заменяется одним из декоративных символов. Пробелы, цифры и знаки препинания остаются как есть.

Каждый запуск выбирает символ случайно, поэтому одна и та же фраза может выглядеть по-разному. Расшифровка возвращает заглавные русские буквы.

Цифра `3` в этом шифре означает букву З. Латинские L, M, H, T, Y и X тоже символы алфавита: при расшифровке они становятся русскими буквами.

## Написать боту

1. Открой [Issues](../../issues) → **New issue**.
2. Выбери **Зашифровать** и вставь текст.
3. Через минуту бот оставит комментарий с шифром.

Чтобы расшифровать, выбери **Расшифровать** или начни текст с `/decrypt`.

Тот же шифр можно запустить вручную: **Actions** → **Nova Cipher** → **Run workflow**. Результат появится в отчёте запуска.

## У себя в терминале

```bash
python3 cipher.py "Привет"
python3 cipher.py --decrypt "вставь_шифр"
```
