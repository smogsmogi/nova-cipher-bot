# NOVA CIPHER

Страница-чат: вводишь русский текст и сразу получаешь шифр. Алфавит лежит в [`cipher.js`](cipher.js) и [`cipher.py`](cipher.py) — одна русская буква заменяется одним декоративным символом. Пробелы, цифры и знаки препинания остаются.

Каждый ответ выбирает символ случайно. «Расшифровать» возвращает заглавные русские буквы.

Часть знаков совпадает с обычными буквами: это тоже варианты шифра. Цифра `3` означает З, латинские N, M, H, T, Y и X читаются как русские буквы.

## У себя в терминале

```bash
python3 cipher.py "Привет"
python3 cipher.py --decrypt "вставь_шифр"
```
